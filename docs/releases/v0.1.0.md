First public release. Rejig is a Mac app for arranging your iPhone's Home Screen: pages, the dock, folders, existing widgets, and which apps live only in the App Library. Nothing is installed on the phone.

## What's in it

- Reads the layout over Wi-Fi (after a one-time USB pairing) or USB. Demo mode uses a pretend phone.
- Lists every change before Apply, saves a backup first, then reads the phone back to check the result. If the check fails, it attempts to restore the backup and reports any rollback failure.
- Restores earlier backups, and writes only to the iPhone a layout came from.
- A local MCP server (`python -m rejig_mcp`) for Claude Code, Codex and Claude Desktop: read the layout and app icons, draft changes, preview the diff, and apply after you approve the numbered changes, in the chat or in Rejig's window. It runs on your Mac and talks only to the Rejig app; what it returns goes to your AI client and its model provider (see [Your data](https://github.com/rejig-app/rejig#your-data)).

## Install

Source install only, no prebuilt app: see [Install](https://github.com/rejig-app/rejig#install) in the README. Requires an Apple silicon Mac on macOS 15 or later, Xcode Command Line Tools and Homebrew Python 3.13.

## Tested on

One iPhone 16 Pro on iOS 27.0.1, over USB and Wi-Fi, from Apple silicon on macOS 26; the AI clients and versions are listed under [Tested on](https://github.com/rejig-app/rejig#tested-on). Apple can change the private Home Screen service in any iOS release, so try Demo first and keep the backups.
